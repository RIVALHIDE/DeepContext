Why we built it

The problem: knowledge and collaboration are disconnected

Important answers live across reports, meeting notes, Office files, images, and architecture diagrams. Generic AI search can expose sensitive material, while separate chat and meeting products force teams to copy answers out of context.

01

Slow discovery

People manually search multiple files and repeatedly ask teammates for the same facts.

02

Security risk

Prompt-only safeguards cannot prevent restricted chunks from reaching an AI model.

03

Broken handoff

Knowledge discovery, discussion, file exchange, and calls happen in separate tools.

How DeepContext solves it

One governed path from upload to action

Upload and validate
Review and approve
Extract and index
Retrieve and verify
Discuss or Huddle

Governed ingestion

  • Mixed multi-file upload with isolated per-file progress and errors
  • PDF, text, Markdown, images, Office, Mermaid, and PlantUML support
  • Member approval queue; editor-or-higher immediate indexing
  • Private object storage for uploaded originals

Grounded intelligence

  • pgvector semantic retrieval plus BM25 keyword ranking
  • Groq-hosted Llama answer generation with streaming
  • LangGraph reflection checks the draft against retrieved evidence
  • Inspectable files, passages, citations, and diagram sources
Zero-trust retrieval: workspace, user, group, and role ACL filters run inside the vector query before top-K selection. Unauthorized content and filenames never enter the LLM prompt.

Proof of Nexconn integration

Nexconn is the collaboration layer—not a decorative embed

DeepContext uses a custom interface built directly on the Nexconn Chat SDK and Nexconn Call SDK. The FastAPI backend keeps the App Secret server-side, issues access tokens, registers opaque provider identities, and deterministically derives one stable Nexconn group channel for every authenticated DeepContext workspace. Switching workspaces therefore switches the collaboration boundary automatically.

C

Nexconn Chat SDK

  • Workspace group channels and message history
  • Real-time send, receive, and message updates
  • Online/offline member presence
  • WhatsApp-style typing indicators
  • Named senders and @mentions
  • Edit-your-own-message workflow
  • Downloadable file attachments with upload progress
H

Nexconn Call SDK

  • One active audio Huddle per workspace
  • Owner starts the room; teammates join the same call
  • Call identity is derived from authenticated workspace membership
  • Collaboration stays beside the knowledge and evidence panels
Governed file collaboration: any member can share a file through Nexconn. Compatible knowledge files become proposals, but only an editor, admin, or owner can add them to the indexed workspace. Chat never bypasses approval or ACL controls.

Product depth and implementation

Built for trustworthy knowledge work

Workspace RBAC

Viewer, member, editor, admin, and owner roles with explicit management capabilities.

Normalized ACLs

Public, user, group, and role tokens replicated to documents and every vector chunk.

Anti-leakage

Uniform refusals prevent disclosure of restricted titles, counts, or document existence.

Evidence panel

Answer citations show the exact permitted files, chunks, and passages retrieved.

Context maps

Mermaid and PlantUML become interactive React Flow diagrams with saved history.

Contribution loop

Approved uploads and cited evidence drive an auditable, workspace-specific leaderboard.
